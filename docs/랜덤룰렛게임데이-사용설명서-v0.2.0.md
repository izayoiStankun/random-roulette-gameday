# 랜덤룰렛게임데이

## 방송 운영자 사용설명서

버전 0.2.0  
작성 기준일 2026-08-02

치지직 실시간 후원, 게임 룰렛, 30분 카운트다운, OBS 오버레이를 한 Windows 앱에서 운영하기 위한 안내서입니다.

> 이 설명서는 실제 방송을 진행하는 방장과 보조 운영자를 위한 문서입니다. 방송 전에 반드시 가상 후원과 OBS 미리보기로 한 차례 리허설하세요.

<!-- pagebreak -->

## 1. 5분 빠른 시작

1. GitHub Release에서 `random-roulette-gameday-0.2.0-beta.3-x64-setup.exe`를 내려받아 설치합니다.
2. 앱을 실행하고 `연동·규칙` 탭을 엽니다.
3. 전달받은 치지직 Client ID와 Client Secret을 입력합니다.
4. `브라우저에서 연결`을 누르고 실제 방송할 방장 계정으로 로그인·동의합니다.
5. `게임 목록`에서 `설치된 Steam 게임 불러오기`를 누르거나 게임을 직접 추가합니다.
6. `OBS 화면 미리보기`로 화면을 확인한 다음 OBS 브라우저 소스를 등록합니다.
7. `후원 요청` 탭의 가상 후원으로 추가·제거 명령을 시험합니다.
8. 운영 모드와 규칙을 확인하고 `룰렛 돌리기`로 시작합니다.

### 방송 직전 체크

- 앱 상단이 `치지직 연결됨` 상태인가?
- Client ID 소유자와 무관하게 로그인한 계정이 실제 방장 계정인가?
- 활성화된 게임과 칸 수가 맞는가?
- OBS 브라우저 소스가 1920×1080으로 표시되는가?
- 수동/자동 모드가 의도한 값인가?
- 4회차 방종 확률과 실패 증감 범위가 맞는가?
- 게임 추가·제거 가상 후원이 정상 반영되는가?
- 카운트다운과 종료 알람 테스트가 선택한 출력에서 들리는가?
- 게임 목록 JSON 백업을 만들어 두었는가?

## 2. 설치와 실행

### 권장: 설치형

`-setup.exe` 파일을 실행해 설치합니다. 설치 위치를 고를 수 있고 바탕 화면 바로가기가 생성됩니다. 앱 안에서 새 버전을 내려받은 뒤 `설치 후 재시작`까지 진행할 수 있으므로 방송용 PC에는 설치형을 권장합니다.

Windows에서 게시자를 확인할 수 없다는 보호 화면이 나오면 파일을 GitHub 공식 Release에서 받은 것이 맞는지 먼저 확인하세요. 확인된 파일이라면 `추가 정보 → 실행`으로 진행할 수 있습니다.

### 포터블

`-portable.exe`는 설치 없이 실행합니다. 새 버전 알림은 받을 수 있지만, 업데이트할 때 Release 페이지에서 새 EXE를 내려받아 직접 교체해야 합니다.

> 방송 중에는 업데이트를 설치하지 마세요. 앱은 새 버전 유무만 확인하며 다운로드와 설치는 운영자가 눌러야 시작됩니다.

## 3. 치지직 연결

### 역할 구분

- Client ID·Client Secret: 개발자센터에 애플리케이션을 등록한 사람의 키를 사용합니다.
- 로그인·권한 동의: 실제 방송을 진행하는 방장 치지직 계정으로 진행합니다.
- 연결 결과: 개발자 앱 아래에 방장 계정의 Access Token이 발급되어 방장의 후원 이벤트를 수신합니다.

### 개발자센터 등록값

- 필요한 Scope: `후원 조회`
- 로그인 리디렉션 URL: `http://127.0.0.1:17554/oauth/callback`

리디렉션 URL은 대소문자, 포트, 경로까지 정확히 같아야 합니다.

### 앱에서 연결하기

1. `연동·규칙 → 치지직 연결`로 이동합니다.
2. Client ID와 Client Secret을 입력합니다.
3. `브라우저에서 연결`을 누릅니다.
4. 열린 브라우저에서 방장 계정으로 로그인하고 권한을 승인합니다.
5. 앱 상단 연결 상태를 확인합니다.

Access Token은 1일, Refresh Token은 30일 동안 유효합니다. 앱이 Access Token을 자동으로 갱신하며, 키와 토큰은 해당 Windows 사용자 계정의 보안 저장소로 암호화해 로컬에 보관합니다. 30일 이상 실행하지 않았거나 인증이 끊기면 브라우저 연결을 다시 진행하세요.

### 키 취급 주의

- 공개 채널, 방송 화면, GitHub 저장소에 Client Secret을 올리지 않습니다.
- 전달이 필요하면 개인 메시지로 보내고 연결 확인 후 메시지를 삭제합니다.
- 유출이 의심되면 개발자센터에서 Secret을 재발급하고 앱에 새 값을 입력합니다.

## 4. 게임 목록 준비

### 설치된 Steam 게임 불러오기

`게임 목록 → 설치된 Steam 게임 불러오기`를 누르면 현재 PC의 Steam 라이브러리 파일을 읽어 설치된 게임을 추가합니다. 인터넷으로 프로필 전체 목록을 가져오는 기능이 아니라, 현재 PC에서 실제 설치가 확인된 게임을 읽는 기능입니다.

미설치 보유 게임이나 Steam 외 게임은 `게임 이름`과 칸 수를 입력해 `직접 추가`합니다. 직접 추가의 기본값은 1칸입니다.

### 목록에서 할 수 있는 작업

- `사용`: 해당 게임을 이번 룰렛에 포함하거나 제외합니다.
- `칸 수`: 게임이 당첨될 상대적인 가중치입니다.
- `전체 확률`: 현재 회차의 방종 확률까지 반영한 실제 당첨 확률입니다.
- `전체 선택`: 현재 목록의 삭제 선택란을 모두 선택하거나 해제합니다.
- `선택한 목록 삭제`: 선택된 게임만 제거합니다.
- `전체 리스트 초기화`: 모든 게임을 제거합니다. 진행 기록 초기화와는 별개입니다.

### 백업과 복원

1. 목록을 준비한 뒤 `리스트 백업`을 눌러 JSON 파일로 저장합니다.
2. 다른 PC나 새 설치에서는 `백업 불러오기`를 눌러 해당 JSON을 선택합니다.
3. 복원하면 현재 게임 목록이 백업 내용으로 교체되므로, 기존 목록이 필요하면 먼저 다시 백업합니다.

백업 파일에는 게임 이름, 칸 수, 사용 여부, 보유·설치 상태 등 게임 목록 정보만 들어갑니다. Client Secret, 치지직 토큰, 위치, 진행 기록은 포함하지 않습니다.

## 5. 확률과 방종 규칙

### 기본 규칙

- 1~3회차: 방종 0%, 활성 게임 전체 100%
- 4회차: 방종 시작 확률 5%, 활성 게임 전체 95%
- 4회차 이후 방종에 실패하면 다음 회차 확률을 기본 `-5~+10%p` 범위에서 무작위 증감
- 방종 확률 최저값은 기본 3%

### 게임별 실제 확률

게임별 확률은 다음 식으로 계산합니다.

`게임 칸 수 ÷ 활성 게임의 전체 칸 수 × 게임 전체 확률`

예를 들어 활성 게임이 총 103칸이고 한 게임이 60칸일 때:

- 1~3회차: `60 ÷ 103 × 100% = 약 58.3%`
- 4회차 방종 5%: `60 ÷ 103 × 95% = 약 55.3%`

4회차에는 모든 게임 확률의 합이 95%, 방종이 5%이므로 전체 합은 100%입니다. 화면과 OBS 모두 이 실제 전체 확률을 표시합니다.

매 회차 방종 확률을 고정으로 5%p씩 올리고 싶다면 실패 증감 최솟값과 최댓값을 모두 `5`로 설정합니다.

## 6. 후원 요청 운영

### 기본 인식 문구

- 추가 접두사: `!게임추가 게임 이름`
- 추가 접미사: `게임 이름 추가요`
- 제거 접두사: `!게임빼기 게임 이름`

접두사와 접미사는 `연동·규칙`에서 바꿀 수 있습니다.

### 금액과 칸 수

- 추가: 후원 1,000원당 1칸
- 제거: 후원 2,000원당 1칸
- 단위보다 작은 나머지 금액은 칸 계산에서 버립니다.

예: 5,000원 `!게임추가 A게임`은 5칸 추가, 5,000원 `!게임빼기 A게임`은 2칸 제거입니다.

### 수동 모드

모든 인식된 요청을 `후원 요청` 탭의 승인 대기열로 보냅니다. 게임명 오타, 청소년 이용불가 게임, 미보유 게임 등을 사람이 확인하기 좋으므로 첫 방송에서는 수동 모드를 권장합니다.

### 자동 모드

보유 또는 설치 확인 여부와 관계없이 유효한 게임 추가 요청을 즉시 룰렛 목록에 반영합니다. 같은 이름의 게임이 이미 있으면 칸 수를 합산하고, 새 이름이면 새 게임으로 등록합니다. 목록에 없는 게임을 제거하는 요청만 승인 대기열로 이동합니다. 타이머가 끝나면 다음 룰렛도 자동으로 진행합니다.

> 후원 메시지의 오타·별칭도 입력된 이름 그대로 즉시 등록됩니다. 후원 이벤트만으로 게임 구매 여부, 연령 제한, 실행 성공 여부까지 판단할 수 없으므로 자동 모드에서는 룰렛 목록과 실제 게임 실행 상태를 운영자가 확인하세요.

## 7. 룰렛과 타이머 진행

1. 활성 게임이 하나 이상인지 확인합니다.
2. `룰렛 돌리기`를 누릅니다.
3. 게임이 선정되면 실제 게임 실행 준비를 마친 뒤 `게임 시작`을 누릅니다.
4. 필요하면 `일시 정지`와 `계속하기`를 사용합니다.
5. 게임을 일찍 끝내면 `조기 종료`를 누릅니다.
6. 타이머가 끝나거나 조기 종료되면 다음 룰렛을 진행합니다.
7. 방종이 당첨되면 이벤트가 종료 상태로 바뀝니다.

`회차·타이머·기록 초기화`는 회차, 현재 타이머, 최근 진행 기록을 초기화합니다. 게임 목록을 지우는 `전체 리스트 초기화`와 구분해서 사용하세요.

## 8. OBS 설정

1. 랜덤룰렛게임데이 앱을 먼저 실행합니다.
2. OBS에서 `소스 추가 → 브라우저`를 선택합니다.
3. 빠른 설정은 URL에 `http://127.0.0.1:17554/overlay/`를 입력합니다.
4. 너비 `1920`, 높이 `1080`으로 설정합니다.
5. `소스가 보이지 않을 때 종료` 옵션은 꺼 두는 편이 안정적입니다.
6. 앱에서 `OBS 화면 미리보기`를 눌러 동일 화면을 확인합니다.
7. 알림음 출력을 OBS로 설정했다면 `OBS를 통해 오디오 제어`를 켭니다.

OBS 주소는 같은 PC 내부의 localhost 통신만 사용합니다. 인터넷 트래픽을 추가로 사용하지 않지만, 앱이 꺼져 있으면 OBS 화면도 표시되지 않습니다.

### 요소별 OBS 소스

`연동·규칙 → OBS Browser Source → 장면별로 배치하는 요소별 OBS 소스`에서 다음 주소를 각각 복사하거나 미리 볼 수 있습니다.

- 통합 화면(무음)
- 룰렛
- 게임 HUD
- 룰렛 목록
- 후원 팝업
- 일출 카운트다운
- 방종 결과
- 알림음 전용

모든 소스는 `1920×1080`으로 등록한 뒤 OBS 장면에서 위치와 크기를 개별 조절합니다. 대기 장면은 목록·후원·일출, 룰렛 장면은 룰렛·후원, 게임 장면은 게임 HUD·후원·일출, 종료 장면은 방종 결과 구성을 권장합니다.

개별 화면 소스는 알림음을 재생하지 않습니다. `알림음 전용` 소스는 화면이 투명합니다. 브라우저 소스를 한 번만 만든 뒤 다른 장면에서는 OBS의 `기존 항목 추가`로 같은 소스를 재사용하세요. 장면마다 새 알림음 소스를 만들면 숨겨진 소스까지 동시에 재생해 소리가 겹칠 수 있습니다. 기존 통합 주소는 호환성을 위해 화면과 소리를 모두 유지하므로 알림음 전용 소스와 함께 사용하려면 반드시 `통합 화면(무음)` 주소를 선택합니다.

### 다음 라운드 미리보기

- ON: 대기 중에 룰렛 목록을 표시합니다.
- 게임 진행 중: 남은 시간 2분부터 목록을 다시 표시합니다.
- 일시정지 중: 목록을 표시하지 않습니다.
- OFF: 목록 미리보기를 숨깁니다.

목록에는 활성 게임의 칸 수와 실제 전체 확률이 표시되며, 4회차부터는 방종 항목도 함께 표시됩니다.

### 썬라이즈 카운트다운

기본값은 OFF입니다. ON을 누르면 현재 위치 사용 경고가 나타나며 동의한 경우에만 Windows 위치 기능을 사용합니다.

- 현재 지역의 일출 시각을 기기에서 계산합니다.
- 일출 1시간 전부터 OBS에 카운트다운을 표시합니다.
- 좌표는 약 1km 단위로 반올림해 Windows 보안 저장소에만 암호화 보관합니다.
- 일반 설정 파일과 OBS 상태 데이터에는 좌표를 넣지 않습니다.

위치 사용이 불편하면 OFF로 두어도 나머지 기능에는 영향이 없습니다.

### 타이머 알림음

- 종료 4초 전: 카운트다운 음원을 한 번 재생합니다.
- 자연스럽게 00:00 도달: 종료 알람을 한 번 재생합니다.
- 조기 종료: 알림음을 재생하지 않습니다.
- 기본 출력: 운영 앱, 볼륨 70%

`연동·규칙 → OBS 표시 옵션 → 타이머 알림음`에서 OFF, 운영 앱, OBS, 둘 다를 선택할 수 있습니다. `카운트다운 테스트`와 `종료 알람 테스트`로 방송 전에 확인하세요.

OBS 출력을 선택하면 브라우저 소스 속성에서 `OBS를 통해 오디오 제어`를 켜야 합니다. 데스크톱 오디오도 캡처하면서 `둘 다`를 선택하면 소리가 중복될 수 있습니다.

## 9. 업데이트

### 채널 선택

- `정식판만`: `v0.2.0`처럼 안정 버전만 확인합니다.
- `테스트판 포함`: `v0.2.0-beta.3` 같은 테스트 버전도 확인합니다.

앱은 시작 후 잠시 뒤 업데이트 유무만 확인합니다. 방송 운영에 영향을 주지 않도록 자동 다운로드와 자동 설치는 하지 않습니다.

### 설치형 업데이트

1. `업데이트 확인`
2. 새 버전이 있으면 `다운로드`
3. 방송이 끝난 뒤 `설치 후 재시작`

### 포터블 업데이트

`Release 페이지`를 열어 새 포터블 EXE를 내려받고 기존 파일을 직접 교체합니다.

## 10. 문제 해결

### 치지직 로그인이 돌아오지 않음

- 개발자센터의 리디렉션 URL이 정확한지 확인합니다.
- `127.0.0.1`, 포트 `17554`, `/oauth/callback`을 다시 확인합니다.
- 앱을 먼저 실행한 상태에서 연결을 다시 시도합니다.

### 치지직은 연결됐지만 후원이 들어오지 않음

- 로그인한 계정이 실제 방송 계정인지 확인합니다.
- 개발자센터 Scope에 `후원 조회`가 포함됐는지 확인합니다.
- `후원 요청`의 가상 후원과 실제 소액 후원을 차례로 시험합니다.
- 장기간 미사용했다면 브라우저에서 다시 연결합니다.

### OBS 화면이 비어 있음

- 앱이 실행 중인지 확인합니다.
- 브라우저 소스 URL과 1920×1080 크기를 확인합니다.
- `OBS 화면 미리보기`가 열리는지 확인합니다.
- 방화벽 경고가 나온 경우 같은 PC의 로컬 연결을 허용합니다.

### 게임이 자동 반영되지 않음

- 자동 모드인지 확인합니다.
- 후원 금액이 추가 1칸 기준인 1,000원 이상인지 확인합니다.
- 제외 문구가 후원 메시지에 포함됐는지 확인합니다.
- 목록에 없는 게임 제거 요청은 승인 대기열을 확인합니다.

### 확률이 예상과 다름

- 체크된 `사용` 게임만 계산 대상입니다.
- 4회차부터 방종 확률을 먼저 뺀 나머지를 게임 칸 비율로 나눕니다.
- 실패 증감 설정 때문에 다음 회차의 방종 확률이 달라질 수 있습니다.

### 알림음이 들리지 않음

- 알림음 출력이 OFF인지 확인합니다.
- 볼륨이 0%인지 확인하고 두 테스트 버튼을 눌러봅니다.
- OBS 출력이라면 브라우저 소스의 `OBS를 통해 오디오 제어`를 켭니다.
- 요소별 소스를 사용한다면 `알림음 전용` 소스가 현재 장면에 하나만 활성화됐는지 확인합니다.
- OBS 오디오 믹서에서 브라우저 소스가 음소거됐는지 확인합니다.

### 초기화 항목을 잘못 누름

- 게임 목록을 지우기 전에는 확인창이 나타납니다.
- 최근 JSON 백업이 있으면 `백업 불러오기`로 목록을 복원합니다.
- 회차·기록 초기화는 게임 목록 백업으로 복원되지 않습니다.

## 11. 방송 당일 권장 진행 순서

1. 앱과 OBS를 실행합니다.
2. 치지직 연결과 OBS 표시를 확인합니다.
3. 게임 목록을 백업합니다.
4. 가상 후원으로 추가·제거를 각각 한 번 시험합니다.
5. 첫 운영은 수동 모드로 시작합니다.
6. 룰렛을 돌리고 게임 준비 후 타이머를 시작합니다.
7. 승인 대기열, 게임 실행, 방종 확률을 함께 확인합니다.
8. 방송 종료 후 업데이트가 있으면 설치합니다.
