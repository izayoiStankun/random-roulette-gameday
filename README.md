# 랜덤룰렛게임데이

치지직 실시간 후원, 게임 룰렛, 30분 카운트다운, OBS 오버레이를 한 Windows 실행파일에서 운영하기 위한 데스크톱 앱입니다.

현재 구현된 규칙:

- 룰렛에서 뽑힌 게임을 기본 30분 플레이
- 4번째 룰렛부터 방종 확률 5%로 시작
- 방종 실패 시 다음 확률을 `-5~+10%p` 무작위 조정, 최저 3%
- 후원 1,000원당 게임 1칸 추가
- 후원 2,000원당 게임 1칸 제거
- 수동 모드: 모든 후원 요청을 승인 대기
- 자동 모드: 보유/설치 여부와 관계없이 유효한 게임 추가 요청을 즉시 반영하고, 타이머 종료 후 다음 룰렛 자동 실행
- 목록에 없는 게임 제거 요청은 승인 대기하며, 청불 여부·실행 가능 여부·미보유 게임 구매는 운영자가 별도 확인
- 활성 게임의 칸 비율을 전체 100% 기준 확률로 표시
- 4회차부터는 방종 확률을 먼저 배정하고, 남은 확률을 게임 칸 비율로 나누어 실제 전체 확률을 표시
- 전체 선택·선택 삭제·목록 초기화와 JSON 목록 백업/복원
- OBS 대기 화면과 다음 라운드 미리보기에 게임 목록·칸 수·확률 표시
- OBS 룰렛·게임 HUD·목록·후원·일출·종료 화면을 요소별 브라우저 소스로 분리 배치
- 선택 동의한 경우에만 현재 지역의 일출을 계산하고, 일출 1시간 전부터 OBS 카운트다운 표시
- 종료 4초 전 카운트다운과 00:00 종료 알람, 운영 앱/OBS/동시 출력 및 볼륨·테스트 설정
- OBS에서 검증된 로컬 룰렛을 기본·고정 사용하며, 회전 중 큰 글씨와 확률 목록을 함께 표시
- 당첨 게임 자동 삭제 ON/OFF와 쉼표로 구분하는 후원 제외 문구
- 명령 없는 일반 후원 메시지를 게임 이름으로 인식하고, 승인 대기와 처리 기록을 분리

## 개발 실행

Node.js 20 이상이 필요합니다.

```powershell
npm install
npm test
npm start
```

## Windows 실행파일 빌드

```powershell
npm run dist
```

`release` 폴더에 `-portable.exe` 무설치판과 `-setup.exe` 설치형이 생성됩니다. GitHub Actions로 자동 빌드할 경우에도 같은 명령을 사용합니다.

## 업데이트와 Release 채널

- 정식판: `v0.2.0`처럼 prerelease 표기가 없는 태그를 사용합니다. 앱의 `정식판만` 채널이 받습니다.
- 테스트판: `v0.2.0-beta.1`처럼 `-beta.N`이 붙은 태그를 사용합니다. GitHub prerelease로 배포되며 `테스트판 포함` 채널이 받습니다.
- 설치형 `-setup.exe`: 앱에서 새 버전을 확인하고, 운영자가 다운로드와 `설치 후 재시작`을 직접 실행할 수 있습니다.
- 포터블 `-portable.exe`: 새 버전을 확인한 뒤 Release 페이지에서 EXE를 내려받아 직접 교체합니다.

앱은 시작 12초 뒤 업데이트 유무만 확인합니다. 방송 중 네트워크와 재시작에 영향을 주지 않도록 자동 다운로드와 자동 설치는 하지 않습니다. GitHub Release에는 EXE와 함께 채널별 YAML 및 설치형 blockmap 파일이 있어야 합니다.

테스트판 배포 예시:

```powershell
git tag v0.2.0-beta.1
git push origin v0.2.0-beta.1
```

태그 푸시 후 GitHub Actions가 Windows 파일을 빌드하고 prerelease를 생성합니다. 실제 자동 업데이트 왕복 테스트는 `beta.1` 설치 후 `beta.2`를 배포해 확인합니다.

## OBS 설정

1. 앱을 먼저 실행합니다.
2. OBS에서 `소스 추가 → 브라우저`를 선택합니다.
3. 빠른 설정은 URL에 `http://127.0.0.1:17554/overlay/`를 입력합니다.
4. 너비 1920, 높이 1080으로 설정합니다.
5. OBS의 `소스가 보이지 않을 때 종료` 옵션은 꺼 두는 편이 안정적입니다.
6. 앱에서 알림음 출력을 `OBS` 또는 `둘 다`로 설정한다면 `OBS를 통해 오디오 제어`를 켭니다.

이 주소는 PC 내부의 localhost 통신만 사용하므로 외부 인터넷 회선을 사용하지 않습니다.

장면마다 위치를 따로 조절하려면 `연동·규칙 → OBS Browser Source → 장면별로 배치하는 요소별 OBS 소스`에서 룰렛, 게임 HUD, 목록, 후원, 일출, 방종 결과 주소를 각각 복사해 별도 브라우저 소스로 추가합니다. 개별 화면 소스는 무음입니다. `알림음 전용` 브라우저 소스는 한 번만 만든 뒤 다른 장면에서 `기존 항목 추가`로 재사용해야 합니다. 통합 화면과 알림음 전용 소스를 함께 쓸 때는 `통합 화면 (무음)` 주소를 사용해야 소리가 중복되지 않습니다.

`다음 라운드 미리보기`가 켜져 있으면 라운드 시작 전과 진행 중 남은 시간 2분부터 게임 목록을 다시 표시합니다. 일시정지 중에는 표시하지 않습니다.

타이머 알림음은 종료 4초 전에 카운트다운을 한 번 재생하고, 자연스럽게 00:00에 도달하면 종료 알람을 재생합니다. 조기 종료에는 종료 알람을 재생하지 않습니다. 기본 출력은 `운영 앱`이며 `연동·규칙 → OBS 표시 옵션`에서 OFF, 운영 앱, OBS, 둘 다와 볼륨을 선택하고 각 소리를 시험할 수 있습니다. 데스크톱 오디오도 캡처하는 환경에서 `둘 다`를 선택하면 소리가 겹칠 수 있습니다.

`썬라이즈 카운트다운`은 기본 OFF입니다. ON을 누르고 위치 사용 경고에 동의한 경우에만 Windows 위치 기능으로 현재 지역을 확인합니다. 좌표는 약 1km 단위로 반올림해 Windows 보안 저장소에 암호화하며 UI, OBS 상태 응답, 일반 설정 파일에는 포함하지 않습니다. 일출 시각은 기기에서 계산합니다.

## 치지직 연결

1. [CHZZK Developers](https://developers.chzzk.naver.com/)에서 애플리케이션을 등록합니다.
2. API Scope에 `후원 조회`를 포함합니다.
3. 로그인 리디렉션 URL을 `http://127.0.0.1:17554/oauth/callback`으로 등록합니다.
4. 앱의 `연동·규칙` 탭에서 Client ID와 Client Secret을 입력하고 연결합니다.

Access Token은 1일, Refresh Token은 30일 유효합니다. 앱은 만료 전 Access Token을 자동 갱신하며, 자격증명과 토큰은 Electron의 Windows 보안 저장소로 암호화해 사용자 데이터 폴더에 보관합니다.

같은 PC에서는 OBS 포트와 후원 처리가 겹치지 않도록 앱을 한 개만 실행합니다. 앱은 두 번째 실행을 감지하면 기존 창을 앞으로 가져옵니다. 서로 다른 PC가 같은 방송 계정으로 동시에 연결하면 양쪽 앱이 같은 후원을 각각 처리할 수 있으므로, 실방송에서는 방송 운영 PC 한 대만 해당 계정에 연결합니다.

기본 로컬 콜백은 치지직 공식 인증 방식과 호환되므로 그대로 사용할 수 있습니다. `sadoloverme.xyz` HTTPS 콜백을 비교 시험할 때 사용할 cPanel 업로드 파일과 절차는 [`hosting/README.md`](hosting/README.md)에 분리해 두었습니다. 웹호스팅에는 Client Secret이나 토큰을 올리지 않습니다.

후원 메시지 기본 인식 형식:

- `게임 이름` (메시지 전체를 추가할 게임명으로 인식)
- `!게임추가 게임 이름`
- `게임 이름 추가요`
- `!게임빼기 게임 이름`

접두사와 접미사는 설정 화면에서 변경할 수 있습니다.

## Steam 게임 목록

`이 PC의 설치 게임 불러오기`는 현재 PC의 `libraryfolders.vdf`와 `appmanifest_*.acf`를 읽습니다. 인터넷 없이 실제 설치·실행 가능한 게임을 확인하는 방식입니다.

OBS PC와 게임 PC가 분리된 경우 `다른 PC의 Steam 보유 게임 불러오기`를 사용합니다.

1. [Steam Web API 키](https://steamcommunity.com/dev/apikey)를 발급합니다.
2. Steam 프로필의 개인정보 설정에서 `게임 세부 정보`를 공개로 바꿉니다.
3. 앱에 대상 프로필 주소 또는 SteamID64와 API 키를 입력합니다.
4. `웹 보유 목록 불러오기`를 누릅니다.

API 키와 프로필 주소는 Electron의 Windows 보안 저장소로 암호화하며, 저장된 API 키는 화면에 다시 표시하지 않습니다. Steam Web API는 보유 목록만 제공하므로 이 방식으로 가져온 게임은 `보유`로 표시됩니다. 게임 PC의 실제 설치 여부는 원격으로 확인하지 않습니다.

## Wheel of Names 룰렛 (일시 보류)

Wheel of Names 회전 영상은 일반 브라우저와 달리 OBS Browser Source에서 빈 화면이 발생하는 환경이 확인되어 `v0.3.0` 정식판에서는 비활성화했습니다. 방송 안정성을 위해 로컬 룰렛으로 자동 전환되며, 저장된 API 키는 삭제하지 않습니다.

호환성 수정이 완료되면 테스트 채널에서 먼저 다시 제공할 예정입니다. API 키는 렌더러나 OBS로 전달하지 않고 Electron 메인 프로세스의 Windows 보안 저장소에만 보관합니다.

`당첨 게임 자동 삭제`를 켜면 당첨된 게임은 결과 확정 후 다음 라운드 목록에서 제거됩니다. `룰렛 제외 문구`에는 `룰렛제외, 게임추가금지`처럼 쉼표로 문구를 나열할 수 있으며, 해당 문구가 들어간 후원은 화면에는 표시하되 게임 추가·제거 요청으로 만들지 않습니다.

## 운영 전에 확인할 점

- “해가 뜨는 시간”은 날짜·지역에 따라 달라 현재 자동 종료 조건으로 쓰지 않고, 방종 당첨 또는 운영자 판단으로 종료합니다.
- 자동 모드에서는 후원 메시지의 게임명이 그대로 즉시 반영되므로 오타·별칭·부적절한 게임명은 운영자가 목록에서 수정하거나 삭제해야 합니다.
- 청소년 이용불가, 실행 실패, 설치 지연, 게임 구매/수수료 확인은 치지직 후원 이벤트만으로 판정할 수 없습니다.
- 방송 전 가상 후원 기능으로 추가·제거 규칙을 반드시 리허설하세요.
